# WeatherNow

Dashboard pengecek cuaca kota menggunakan API publik (Open-Meteo, tanpa API key) lengkap dengan perkiraan 7 hari.

## Fitur
- Mencari cuaca berdasarkan nama kota
- Perkiraan suhu min/max hari ini
- 7 hari ke depan (min/max suhu dan deskripsi cuaca)
- Kecepatan angin dan kelembaban
- Ikon cuaca
- Responsif untuk desktop dan mobile

## Menjalankan
Buka `index.html` di browser, atau:
```bash
python3 -m http.server 8080
```
